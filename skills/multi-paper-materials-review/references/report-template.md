# Full linked-review reference

Read for a full multi-paper synthesis. Select sections and table columns that answer the user's question; this is an extraction aid, not a mandatory report outline.

## Coverage and paper records

Read each supplied paper fully and consult relevant available SI. Track missing sources and unreadable regions. For each paper, capture its contribution, evidence, material/synthesis/test conditions, limitations, and relation to the other papers. A concise paper record can replace multiple repetitive tables.

| Field | Capture when relevant |
|---|---|
| Source | Paper ID, title, year, journal, DOI/version, source and SI coverage |
| Contribution | The specific advance claimed and what its data actually establish |
| Material | Composition/phase, defect or dopant state, coating/composite, morphology, size |
| Synthesis | Precursors, ratios, solvents, atmosphere, temperature/time, post-treatment, scale and repeats |
| Structural evidence | Method, sample/state, measured change, figure/panel/table/page, uncertainty |
| Electrode/cell | Active/conductive/binder ratio, loading, collector, electrolyte, separator, reference/counter electrode, format |
| Testing | Voltage, actual current/C-rate definition, temperature, activation, cycle indices, relevant CV/EIS/GITT/PITT settings |
| Performance | Original capacities, ICE/CE, rate and cycling results, retention baseline, impedance/diffusivity and assumptions |
| Mechanism | Observation, author explanation, reviewer inference, competing explanations |
| Limits | Missing controls, repetitions, uncertainty, reporting gaps, comparison restrictions |

Keep evidence locations attached to the values, not only in a bibliography. Figure extraction is unnecessary for unneeded panels; inspect and retain readable supporting visuals when requested for the deliverable.

## Fair comparisons

Record the physical quantity, state, and denominator before converting units. In battery papers distinguish active-material mass, whole-electrode mass, either electrode in a full cell, combined active masses, areal capacity, and volume basis. Retention needs both endpoint and reference cycle/capacity. Distinguish reported C-rate from actual current; do not infer a common capacity basis.

An optional performance table:

| Paper/source location | Material/cell | Conditions and loading | Current and basis | Value and denominator | Cycle/reference | Comparability limit |
|---|---|---|---|---|---|---|

Do not rank intrinsic transport from unmatched particle sizes, electrode recipes, or model-derived diffusion coefficients. A superior headline value under a different regime is a separate result, not evidence of a universally better material.

## Synthesis

Organize around the findings, not repeated abstracts. Link improvements or conceptual inheritance to actual citations, shared designs, and evidence. If the selected set does not establish historical priority or field-wide trends, state that scope limitation. A timeline or diagram is useful only when the relations are supported.

Use a support/conflict table when it clarifies the result:

| Question | Supporting evidence | Contradicting evidence | Condition/model differences | Remaining interpretation | Discriminating test |
|---|---|---|---|---|---|

A full report can combine scope and verdict, concise paper records, comparison evidence, mechanisms and conflicts, and unresolved questions. Add writing-ready prose, slides, or innovation ideas only when they serve the requested deliverable. Avoid fixed sentence counts, duplicated summaries, or compulsory sections with no evidence.

## Research directions when requested

For each idea, identify the source gap, hypothesis, controlled variable, fastest discriminating control, expected measurement, falsifying outcome, and practical risk. Lack of coverage in the supplied papers is not proof that an idea is novel across the field.
