# Adaptable slide cards

Use for a complete outline. Follow the user's example or requested fields instead of requiring every field here.

Begin with the topic, audience, duration/slide count if known, source set, and material limitations. Then describe the argument in a few sentences. Avoid repeating this setup on multiple introductory slides.

## Compact default

```markdown
### 第 N 页：有证据支持的标题

页面文字：可直接放入幻灯片的短句；保留关键数据、单位或比较条件。

配图：来源 ID，Fig./Table 与 panel，PDF 页码；选取范围、摆放建议及用途。

讲图稿：自然口语解释实验对象、如何读关键图、结果及其边界，并接到下一页。
```

Add a separate `本页作用`, layout sketch, per-panel explanation, transition, or citation line only when it adds useful detail. The figure's source locator can live directly beside the visual plan. Do not impose a minimum bullet count, number of images, or paragraphs per slide.

## Figure explanation

The speaker should be able to explain what is measured, which samples/conditions are compared, how to read relevant axes/legends, the most useful number or trend, and what supports the slide claim. If one slide cannot show enough labels or explain all its panels legibly, narrow the chosen panels or split the slide.

For comparisons, retain normalization, operating conditions, uncertainty, and source provenance. In battery talks, this can include cell type, capacity basis, loading, rate/current definition, voltage window, temperature, and pressure where relevant. Missing conditions reduce comparability; they are not permission to assume equality.

## Optional supporting tables

A visual index is useful for long talks or requested crop packages:

| Slide | Source ID | Figure/panel and PDF page | Crop/asset path | Purpose or limitation |
| --- | --- | --- | --- | --- |

List missing SI, unverified figures, or unclear values only when they affect the talk. Keep unresolved items actionable: specify what is needed and which claim or slide it changes. A glossary or separate teaching guide is optional.
